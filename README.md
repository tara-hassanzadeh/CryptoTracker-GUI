# 🪙 CryptoTracker-GUI

A simple and modern desktop cryptocurrency price tracker built with **Python** and **Tkinter**.

CryptoTracker-GUI connects to the **CoinGecko API** to retrieve real-time cryptocurrency prices and displays them in a clean graphical interface.

---

## ✨ Features

- 🖥️ Desktop GUI built with Tkinter
- 💰 Real-time cryptocurrency prices
- 🌐 CoinGecko API integration
- 🔄 Manual price refresh
- ⚡ Automatic price loading when the application starts
- 💵 USD price display
- 📊 Multiple cryptocurrencies in one API request
- 🛡️ Basic API error handling
- 📦 No external Python packages required
- 🎨 Clean and simple user interface

---
